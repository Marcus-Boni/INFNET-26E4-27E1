--------------------------------------------------------------------------------

montado em /sys. Ele expõe a hierarquia de dispositivos, barramentos, drivers e

4. INTERPRETAÇÃO TÉCNICA DOS ATRIBUTOS LIDOS
--------------------------------------------------------------------------------
- dev                     : 8:64 (Major 8 = driver SCSI disk 'sd'; Minor 64 = disco sde).
- size                    : 2147483648 setores de 512 bytes = 1099511627776 bytes (~1024 GiB / 1 TiB).
- ro                      : 0 (0 indica dispositivo habilitado para leitura e escrita).
- removable               : 0 (0 indica disco fixo / não removível).
- device/vendor e model   : Fabricante 'Msft' | Modelo 'Virtual Disk'.
- logical/physical_block  : Setor lógico de 512 B e setor físico de 4096 B (4K aligned).
- stat                    : Contadores em tempo real de operações de leitura/escrita (I/O) do kernel.
