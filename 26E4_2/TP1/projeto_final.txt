3. INVESTIGAÇÃO DOS COMANDOS UTILIZADOS COM COMANDOS AUXILIARES
--------------------------------------------------------------------------------
Investigando os utilitários 'file' e 'less' com 'type', 'which', 'whatis' e 'man':

marcus@ubuntu-wsl:~/projeto_final$ type file less ls
file is /usr/bin/file
less is /usr/bin/less
ls is hashed (/usr/bin/ls)

marcus@ubuntu-wsl:~/projeto_final$ which file less ls
/usr/bin/file
/usr/bin/less
/usr/bin/ls

marcus@ubuntu-wsl:~/projeto_final$ whatis file less ls
file (1)             - determine file type
FILE (3)             - overview of system data types
less (1)             - opposite of more
ls (1)               - list directory contents

marcus@ubuntu-wsl:~/projeto_final$ man file | head -n 20
FILE(1)                   BSD General Commands Manual                  FILE(1)

NAME
     file — determine file type

SYNOPSIS
     file [-bcdEhiklLNnprsSvzZ0] [--apple] [--exclude-quiet] [--extension]
          [--mime-encoding] [--mime-type] [-e testname] [-F separator]
          [-f namefile] [-m magicfiles] [-P name=value] file ...
     file -C [-m magicfiles]
     file [--help]

DESCRIPTION
     This manual page documents version 5.41 of the file command.

     file tests each argument in an attempt to classify it.  There are three
     sets of tests, performed in this order: filesystem tests, magic tests,
     and language tests.  The first test that succeeds causes the file type to
     be printed.
